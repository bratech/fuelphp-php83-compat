# Compatibility release 1.0.2

This release fixes PHP 8.3 deprecation warnings in `Image_Driver::_resize()` when width or height is omitted. Only the percentage-suffix checks cast their arguments to strings. Dimension inference, aspect ratios, percentage inputs and `InvalidArgumentException` for two omitted dimensions are preserved.

## Upgrading

With the old compatibility package still installed, stop application processes and reverse its patches using its own tool. Then update to `bratech/fuelphp-php83-compat:1.0.2`, apply the new patches and run `check` and application tests. See the [1.0.1 to 1.0.2 upgrade commands](../OPERATIONS.md#upgrading-from-101-to-102).

The release is a cumulative patch set, not a patch to apply over 1.0.1. Existing tags are unchanged. FuelPHP and upstream dependency versions are unchanged.

## Verification and limits

- All 13 resize cases passed on PHP 7.4 and 8.3 with both GD and ImageMagick. The GD results also matched the pre-fix PHP 7.4 baseline.
- The existing MySQLi full suites and their PHP-version comparison passed. Distribution CLI tests and patch application/reversal checks passed.
- Two existing GD mask failures remain: `mask_file` and `mask_taller_than_source`. Their results were identical before and after this fix.
- Imagick, every database configuration and production application integration were not tested for this release. Existing limitations in [verification scope](../VERIFICATION.md) still apply.
