# Compatibility release 1.0.0

Initial compatibility set for FuelPHP 1.8.2 on PHP 7.4 and 8.3. The compatibility version is independent of FuelPHP's version.

- Provides package-level patches and a PHP CLI: `status`, `check`, `apply`, and `reverse`.
- Verifies installed versions, source references and file hashes before writing. Failed replacements trigger restoration; failed restoration retains recovery information.
- Supports seven packages and eight package/version combinations. Upload 2.0.10 is verified against known official sources without applying an additional patch. Optional packages are not installed automatically.
- Requires PHP `^7.4 || ~8.3.0`, Composer 2, Git, and ICU/ext-intl in CLI and Web PHP.

Use the GitHub VCS repository and require `bratech/fuelphp-php83-compat` at `1.0.0`. Configure the application's root Composer scripts to run `apply` and `check` before existing Oil installation hooks. Installing this package alone does not apply its patches.

Read the [installation instructions](https://github.com/bratech/fuelphp-php83-compat/blob/v1.0.0/README.md), [Japanese instructions](https://github.com/bratech/fuelphp-php83-compat/blob/v1.0.0/docs/README.ja.md), [behavior changes](https://github.com/bratech/fuelphp-php83-compat/blob/v1.0.0/docs/BEHAVIOR_CHANGES.md), and [recovery procedure](https://github.com/bratech/fuelphp-php83-compat/blob/v1.0.0/docs/OPERATIONS.md) before applying it.

Known conditions include ICU-dependent date output, database-result memory use, and Model_Crud's new serialized form. Unpatched PHP 7.4 cannot read that new form; removing patches may require invalidating affected sessions/caches or restoring compatible persistent data. MySQL-family connections were tested with MariaDB, not Oracle MySQL.

The recorded phpseclib medium advisory remains. This compatibility release is not a package-wide security guarantee. The [verification scope](https://github.com/bratech/fuelphp-php83-compat/blob/v1.0.0/docs/VERIFICATION.md) distinguishes tested behavior from exclusions and records the audit conditions.

Release validation on 2026-10-22: Composer 2.8.1 installed the exact version `1.0.0` from the public GitHub VCS repository in all four PHP/layout configurations. Apply, check, repeated operations, reverse, clean installation hooks and the associated regression tests passed. All 28 downloaded package files matched the tag. GitHub API authentication was used after the anonymous API quota was exhausted; upstream dependencies remained fixed local ZIP fixtures. This was not a new dependency audit.
